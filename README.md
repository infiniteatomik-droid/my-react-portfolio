# 🛒 Gadget Space — Коммерческий интернет-магазин гаджетов

Современное одностраничное приложение (SPA) для покупки электроники, разработанное на React с использованием продвинутого стейт-менеджмента и интеграцией с внешним REST API.

🔗 **Живое демо проекта:** [infinite-gadget-shop.netlify.app](https://infinite-gadget-shop.netlify.app)

---

## 🛠 Технический стек

*   **Core:** React 18 (Функциональные компоненты, Hooks).
*   **State Management:** Redux Toolkit (управление корзиной, каталогом, статусами загрузки и фильтрацией).
*   **Data Fetching:** AsyncThunk / Fetch API для асинхронных запросов.
*   **Routing:** React Router v6 (декларативный роутинг, динамические маршруты для деталей товара).
*   **Styling:** Tailwind CSS (адаптивная верстка, кастомные UI-компоненты).
*   **Build Tool:** Vite (быстрая сборка и оптимизация продакшн-бандла).
*   **Hosting:** Netlify (с настроенной конфигурацией проксирования роутов для предотвращения 404 ошибок).

---

## 🚀 Реализованный функционал и бизнес-логика

*   **Динамический каталог:** Интеграция с DummyJSON API, асинхронное получение данных о товарах, обработка состояний загрузки (`loading`, `error`, `fulfilled`).
*   **Улучшенный UX (Skeleton UI):** Кастомные анимации загрузки карточек товаров для предотвращения эффекта «прыгающего интерфейса».
*   **Поиск и фильтрация:** Реализована клиентская фильтрация товаров по категориям и интерактивный поиск в реальном времени.
*   **Пагинация каталога:** Постраничный вывод товаров для оптимизации работы с большими массивами данных и снижения нагрузки на интерфейс.
*   **Глобальный модуль корзины (Redux):**
    *   Добавление, удаление и динамическое изменение количества товаров.
    *   Автоматический сквозной пересчет общего количества позиций и финальной стоимости заказа.
    *   Валидация стейта при операциях с корзиной.
*   **Безопасность конфигурации:** Все чувствительные данные и базовые адреса API вынесены в изолированные переменные окружения (`.env.local`).

## 📂 Архитектурная структура проекта

Проект организован по модульному принципу, приближенному к коммерческим стандартам разработки (Feature-Based Architecture):

*   `src/app/` — глобальная конфигурация приложения (Redux Store).
*   `src/components/` — общие UI-компоненты (Footer, Header, Скелетоны).
*   `src/features/` — изолированные модули бизнес-логики (продукты, корзина) со своими слайсами (`slice.js`).
*   `src/pages/` — компоненты верхнего уровня, отвечающие за отрисовку конкретных экранов приложения.
*   `public/` — статические ресурсы и конфигурационные файлы сервера (`_redirects`).
